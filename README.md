# HR Employee Attrition & AI Adoption Analysis (SQL)

### 📌 Project Overview
This project explores an HR dataset to understand employee attrition patterns, burnout trends based on work modes, and the impact of AI tool adoption across different departments. The complete Exploratory Data Analysis (EDA) and business intelligence queries were written in **PostgreSQL**.

### 🛠️ Tools & Technologies Used
* **Database Engine:** PostgreSQL
* **IDE/Tool:** pgAdmin 4
* **Techniques:** Aggregate Functions, Data Filtering (WHERE), Schema Validation, Data Cleaning (NULL checks), and Data Formatting (ROUND).

### 💡 Key Questions Answered in the SQL Script
1. What is the overall employee attrition count?
2. Which work mode (Remote, Hybrid, Onsite) experiences the highest employee burnout?
3. Which departments have the highest and lowest adoption of AI tools?
4. Which departments feel the highest perceived risk of AI replacing their jobs?
5. What is the average salary and headcount distribution across various departments?

### 📂 Files in this Repository
* `b_2.sql` : Contains the fully commented SQL script with all queries used for this analysis.

### 🚀 How to Use
You can run the `b_2.sql` script on any PostgreSQL database environment after importing your standard HR Employee dataset.
